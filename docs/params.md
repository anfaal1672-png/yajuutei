# 採用したパラメータ（MASTER_PROMPT.md §4）

値は `src/params.py` にあり、書き換えて `make` すると反映されます。

| パラメータ | 採用した値 | 理由 |
|---|---|---|
| `ERA` | `hybrid`（＋比較用に `2001` 版も同時に生成） | 既定値どおり。外観は 2020年代の写真、内装は作中準拠。2001年版は前面の増築棟を作らず、前面を駐車スペース＋門付き階段にしたもの（写真③の状態） |
| `SCALE` | 水平 1.25（1ブロック＝0.8m）、階高 4ブロック | 階高 4ブロック（天井高3）にすると縦が 1.33倍になるので、外形の縦横比が崩れないよう水平も上限の 1.25 にした（assumptions A-01） |
| `SITE` | `block`（敷地＋前面道路＋東の交差道路＋両隣と向かいの雰囲気） | 既定値は「敷地＋接する道路2本」。写真①②に写っている隣の建物・擁壁がないと見比べにくいので、雰囲気だけ足した（特定の家は再現していない） |
| `INTERIOR` | `all` | 既定値どおり。作中の部屋（玄関・リビング・浴室・屋上・地下室）は詳しく、他は簡素に |
| `TARGET` | Windows版／スマホ版（.mcpack をインポート） | 既定値どおり。ゲーム機は Realms 経由（HOW_TO_PLAY.md） |
| `VERSION` | 最新安定版 **1.26.50**（Mojang/bedrock-samples のタグ v1.26.50.4、2026-09-15） | 実行時点の最新の安定版を公式のサンプルリポジトリで確認した |
| （追加）互換版 | **1.21.130〜1.26.40** 用のパックも作る | 1.26.50 で柵・ガラス板・鉄格子の接続状態が新しく加わり、古い版ではその書き方がエラーになるため |

`functionCommandLimit` 対策: 建築全体のコマンド数は約1,000（上限 10,000 の約1割）なので、`build_all` 1回で建つ方式にした。
