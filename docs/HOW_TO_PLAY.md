# 遊び方（Minecraft 統合版）

## 1. どのパックを使うか

`dist/` に4つのパックがあります。ゲームのバージョン（タイトル画面の右下）で選んでください。

| ファイル | 中身 | 対応バージョン |
|---|---|---|
| `yajuutei_hybrid_latest.mcpack` | **おすすめ**。外観は2020年代の写真、内装は作中準拠 | 1.26.50 以降 |
| `yajuutei_hybrid_compat.mcpack` | 同じ建物 | 1.21.130〜1.26.40 |
| `yajuutei_2001_latest.mcpack` | 作中当時（2001年）の推定。前面の増築棟がなく、門付きの階段 | 1.26.50 以降 |
| `yajuutei_2001_compat.mcpack` | 同じ建物 | 1.21.130〜1.26.40 |

最新版用と互換版用の違いは、ガラス板・鉄格子・柵のつながり方を書いているかどうかだけです（1.26.50 で書き方が増えたため）。

## 2. パックを入れる（Windows・スマホ）

1. `.mcpack` ファイルを端末にコピーして開く → Minecraft が起動して「インポートしました」と出る。
2. 新しいワールドを作る:
   - 「ワールドタイプ」を **フラット**（スーパーフラット）にする（周りの地形と段差ができないように）
   - 「チート」を **オン** にする（コマンドを使うため。実績は解除されなくなります）
   - 「ビヘイビアパック」→「入手済み」から **野獣邸 再現** を選んで「有効にする」
3. ワールドに入る。

## 3. 建てる

建物は、**コマンドを打った人の足元を「前面道路の真ん中」として、その北側（z がマイナスの方向）に建ちます**。
範囲は、足元から 西に21・東に27・北に32・南に6・上に23 ブロック（約 49×24×39）です。

1. 何もない平らな所に立つ（フラットのワールドなら、そのままでよい）
2. チャットで次の2つを順に実行する:
   ```
   /function yajuutei/setup
   /function yajuutei/build_all
   ```
   - `setup` はこの範囲を読み込み範囲（tickingarea）に登録します。
   - `build_all` で一気に建ちます（コマンド約1,000個、数秒）。チャットに「完成しました」と出れば終わりです。
3. 場所を正確に決めたいときは、立つ代わりに座標を指定できます:
   ```
   /execute positioned 0 -60 0 run function yajuutei/build_all
   ```
   （フラットのワールドの地面の上は y=-60）

### 消す・建て直す
- 消す: 建てたときと**同じ場所**で `/function yajuutei/clear`（範囲を空気にして、地面を草ブロックに戻す）
- 建て直す: `/function yajuutei/clear` → `/function yajuutei/build_all`
- 読み込み範囲の登録を消す: `/function yajuutei/remove_tickingarea`

### 部屋だけ置き直す
`/function yajuutei/rooms/<部屋>` で、その部屋の家具だけをもう一度置けます。
部屋の名前: `living`（リビング）、`kitchen`（台所）、`genkan`（玄関）、`bath`（浴室）、`basement`（地下室）、`bedroom`、`study`、`toilet`、`washitsu`（和室）、`storage`、`garage`、`annex_office`、`annex_room`、`annex_terrace`

## 4. 中の歩き方

- 正面の道路から、建物の右（東）の**外階段**を上がると、突き当たりが玄関ポーチです。
- **玄関の扉とガレージ側の扉は鉄の扉**なので、横の**石のボタン**を押すと開きます（統合版の鉄の扉は手で開きません）。
- 屋内の階段は北西の奥。地下室 → 1階 → 2階 → 3階 → 塔屋 → **屋上**まで続いています。
- 3階の和室から南のテラスに出て、西の端の段を上がると、前面の棟の屋上テラスに行けます。
- 夜は室内の見えない光源で明るくなります。

## 5. ゲーム機（Switch・PlayStation・Xbox）で遊ぶ

ゲーム機はパックを直接読み込めません。

1. Windows かスマホで上の手順どおりに建てる。
2. そのワールドを **Realms** にアップロードする（ワールドの編集 →「Realms にアップロード」）。
3. ゲーム機で Realms からダウンロードする。

同じ端末の別のワールドに写すだけなら、建てたワールドで次を実行して保存し、
```
/structure save yajuutei ~-21 ~-1 ~-32 ~27 ~23 ~6 false disk
```
写したいワールドで `/structure load yajuutei <座標>` を実行する方法もあります（構造物の保存はワールドごとなので、別のワールドに写すにはワールドのコピーが必要な場合があります）。

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| `/function` が見つからないと言われる | ワールドの設定でビヘイビアパックが有効か、チートがオンかを確認 |
| 関数の読み込みエラーが出る | 最新版パックを古いバージョンで使っている可能性。互換版パックに替える |
| 一部だけ建たない | 範囲が読み込まれていない可能性。`setup` を実行してから少し待ち、`build_all` をもう一度 |
| 周りの地形と段差がある | フラットのワールドで建てる |
